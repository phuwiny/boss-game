## 0. บริบทสั้น

Coin Quest เป็นเกม platformer HTML5 Canvas ไม่มี build step สเตจ 4 คือ **บ้านผีสิงฮัลโลวีน** ลึกลับ มืดสลัวเล็กน้อย มีฟักทองประหลาด บางลูกยิงลูกไฟ กลไกหลักคือ **บล็อกสวิตช์สีม่วง/ส้ม** และ **แพลตฟอร์มเลื่อนขึ้นลง**

Claude ทำ gameplay และ motion ฝั่ง code แล้วนำภาพเข้าเกมเอง งานของ Codex คือ **สร้างภาพด้วย imagegen skill** ส่งไฟล์เข้า `assets/` พร้อม log ตามแนวทางเดิม (`.logs/2026-10-13_imagegen.md`, `.logs/2026-10-14_visual-art-direction.md`, `.logs/2026-10-15_character-concept-rebuild.md`)

**ห้ามแก้ไฟล์ใน `js/`, `css/`, `index.html`** ในงานนี้ — ส่งเฉพาะภาพ, source sheet, preview และ log

## 1. Style และข้อห้ามรวม

- อ้างอิงสไตล์: `assets/concepts/2026-10-14_scene-concepts.png` และ `assets/concepts/2026-10-14_character-lineup-final.png` — pixel art สไตล์ 16-bit เส้นขอบเข้ม เงา 3 ระดับ โทนเดียวกับ 3 สเตจเดิม
- บรรยากาศ: **ลึกลับแต่ไม่น่ากลัวเกินไป** (ผู้เล่นมีเด็ก) — ฟักทอง "ประหลาด/ทะเล้น" มากกว่า "สยอง" ไม่มีเลือด ไม่มีโครงกระดูกสมจริง
- Palette หลัก: ม่วงเข้ม/น้ำเงินกลางคืน + ส้มฟักทอง + เขียวผีเป็นสีเน้น
- ไม่มีข้อความ โลโก้ watermark หรือ UI วาดติดภาพ
- ภาพที่ใช้ในเกมจริงต้องเป็น PNG โปร่งใส (sprite/tile) หรือ WebP (ภาพใหญ่) เก็บต้นฉบับ PNG ไว้ใน `assets/concepts/`
- ชื่อไฟล์ขึ้นต้นด้วยวันที่สร้าง `YYYY-MM-DD_` ตามแบบ repo

ทุกชิ้นเป็น PNG โปร่งใส ออกแบบบน **grid 32×32 logical px** ส่งที่ **density 2 (64×64 ต่อช่อง)** วางเป็น sprite sheet ช่องละเท่ากัน มีขอบโปร่งรอบช่องอย่างน้อย 2 px

| ไฟล์ | ช่อง/เฟรม |
|---|---|

| `assets/haunted/YYYY-MM-DD_switch-blocks.png` | บล็อกม่วง **ทึบ** + **โปร่ง** (กรอบเส้นประ), บล็อกส้ม **ทึบ** + **โปร่ง**, สวิตช์ 3 เฟรม (ปกติ / ถูกกด / ไฟสถานะสีตามปัจจุบัน) |
| `assets/haunted/YYYY-MM-DD_vplatform.png` | แพลตฟอร์มแนวตั้งกว้าง 3 ช่อง (96×14 logical) + รางแนวตั้ง 1 ช่อง |

| `assets/haunted/YYYY-MM-DD_pumpkin-fire.png` | ฟักทองยิงไฟ 32×32 logical: ปกติ, **ตาเรืองแสง/สั่นเตือน** (2 เฟรม), ยิง, โดนยิง (กะพริบ), แตก (3 เฟรม) |
| `assets/haunted/YYYY-MM-DD_fireball.png` | ลูกไฟผี 16×16 logical 4 เฟรมวน — **สีต่างจากลูกไฟบอสเต่า** (เขียวผีหรือม่วง) |

**ข้อบังคับ accessibility:** บล็อกม่วงและส้มต้อง **แยกได้ด้วยลาย** ไม่ใช่สีอย่างเดียว — ม่วง = ลายพระจันทร์เสี้ยว/วงกลม, ส้ม = ลายสี่เหลี่ยม/หน้าฟักทอง ตรวจด้วยภาพ grayscale ว่ายังแยกออก

### ชุด 4 — เฟรมตัวละครเพิ่ม (เฉพาะสเตจ 4)

**นี่คือส่วนที่เสี่ยงที่สุด** เมื่อ 2026-10-16 ชุด run5–8 ถูกยกเลิกเพราะสัดส่วนเพี้ยน (ดู PLAN.md หัวข้อ "ขอบเขตที่พินอนุมัติเพิ่ม") จึงต้องทำตามขั้นนี้:

1. **Seed ก่อน:** สร้างภาพ 1 ท่าต่อตัว (`run1` ใหม่) วางเทียบกับ `idle` เดิมของตัวเดียวกันในภาพเดียว ส่งพินตรวจ **หยุดรอ**
2. หลังผ่าน seed → สร้าง **source sheet ต่อตัวละคร** grid 4×4 ช่องเท่ากัน (ช่องสุดท้ายเว้นว่าง) ลำดับ:
   `run1–run8`, `jumpUp`, `jumpApex`, `jumpFall`, `land`, `dead1`, `dead2`, `dead3`
   ชื่อไฟล์ `assets/characters/YYYY-MM-DD_<bobo|mew|aclaire>-motion-v2-source.png`
3. ตัวละครในทุกช่อง **ห้ามแตะขอบช่อง** (ตัว normalize เดิมจะ throw)

**ล็อกไว้ ห้ามเปลี่ยน:**
- Logical frame **54×48**, density 2 (backing 108×96), anchor `ax = 32` — ตาม `tools/2026-10-15_build-character-art.cjs`
- **สเกลต้องเท่าชุด 9 ท่าที่ใช้อยู่** (ความสูงตัวในเฟรม: Bobo ~31 px, Mew/Aclaire ~43 px logical) — ตรวจโดยวางทับ `idle` เดิม
- เอกลักษณ์: Bobo **ไม่มีปาก** ก้อนกลมส้ม คาดผ้าฟ้า; Mew ผมยาวเหลือง **ตาเขียว** เสื้อน้ำเงินเข้ม กระโปรงส้ม หมวกเบเร่ดำ; Aclaire ผมสั้นส้มหางม้า **ตาฟ้า** เสื้อชมพู กางเกงน้ำเงิน; หันขวาเสมอ (เกม flip เอง)
- Aclaire ใช้ท่าแกว่งแขนสลับแบบ `assets/characters/2026-10-17_aclaire-arm-swing-source.png`

**ความหมายของท่า:**
- `run1–8`: รอบวิ่งเต็ม 1 รอบ (contact → down → pass → up ×2 ข้าง) เท้าแตะพื้นที่บรรทัดเดียวกันทุกเฟรม
- `jumpUp` ตัวยืด แขนขึ้น / `jumpApex` ตัวกลาง ๆ ขาพับ / `jumpFall` แขนกาง ขาเหยียดลง
- `land` ย่อตัวรับแรง (เกมจะใช้ 1–2 เฟรมตอนแตะพื้น)
- `dead1` ตกใจ (ตาโต) / `dead2` ตาเป็นวง หมุนกลางอากาศ / `dead3` ร่วงลง — โทนการ์ตูน ไม่เจ็บปวด

## 3. สิ่งที่ต้องส่งกลับ

- ไฟล์ภาพตามตารางข้างบน (ต้นฉบับ PNG ใน `assets/concepts/` ถ้ามีการ crop/optimize)
- Preview รวม: `assets/haunted/YYYY-MM-DD_preview.png` วางทุกชิ้นบนพื้นมืด + พื้นสว่าง และภาพ grayscale ของบล็อกสวิตช์
- Preview ตัวละคร: วางเฟรมใหม่ทั้งหมดเทียบ `idle` เดิมในสเกลจริง (ขนาด 1× และ 3×)
- Log: `.logs/YYYY-MM-DD_haunted-imagegen.md` — prompt ทุกภาพ, path ต้นฉบับใน Codex `generated_images`, ขนาดไฟล์, วิธี optimize, สิ่งที่ยังไม่ได้ตรวจ
- **ไม่ต้อง** แปลงเฟรมตัวละครเป็น `js/*-character-art.js` — Claude จะขยาย build script และต่อเข้าเกมเอง
