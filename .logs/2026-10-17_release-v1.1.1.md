# Coin Quest v1.1.1 — release notes

Mew's Memory Match portrait now faces the viewer with a small cheerful open smile. The game manual shows portraits for Bobo, Mew and Aclaire, and its web view displays the same images. An Aclaire running source sheet with a clearer alternating arm pose is included for future sprite work; the in-game run animation is unchanged.

## Changes

- **Memory Match:** Use the revised Mew portrait on cards. The existing sprite remains the loading/error fallback.
- **Game manual:** Add all three character portraits and their text alternatives. Update the version information and explain the Grassland backdrop. The web manual now renders portrait images from `MANUAL.md` in a compact layout.
- **Character art source:** Add a separate Aclaire 3×3 source sheet with a revised center Run frame. It is not wired into runtime sprites.

## Release context

This release follows [v1.1](https://github.com/phuwiny/boss-game/releases/tag/v1.1). Since that tag, [PR #23](https://github.com/phuwiny/boss-game/pull/23) added MP3 music for Grassland, Forest, and Castle, and moved the original synthesized tune to menus and Rock–Paper–Scissors. The music changes are already on `main` and are included in the v1.1.1 release target.
