# Real-input timed play — 2026-10-15

Scope: three complete timed rounds at 844×390: Grassland/Bobo, Forest/Mew, Castle/Aclaire. This covers each stage and character once, not the full nine character/stage combinations and not normal-mode completion.

Unlike the earlier result/arena fixtures, this script never writes game position, HP, coins, timer, boss state, or randomness. CQ.debug is read-only for observation and basic input decisions. All movement/jump/fire uses Playwright keyboard events; timers and enemy collisions run normally. Custom seed `qa-liveplay-2026-10-15` prevents main-game record writes. The controller may make poor decisions; bot failure to traverse an obstacle is not automatically a product defect.

Coverage: real timer expiry (or genuine completion), death/respawn during play if encountered, coin collection, actual result screenshot, replay resets timer/coins, pause/home after replay. Trace samples every two seconds record location/time/coins/deaths and boss HP. Maximum x is reported separately so a timed-round finish is never mislabeled as whole-level traversal or boss victory.

The existing check-level.js uses a physics search with stationary substitutes for moving platforms and no enemies/boss/rocks; it does not replace this browser playtest and was not rerun for this visual-only change.
