# Coin Quest v1.2 — เพลงประกอบสเตจ

เพิ่มเพลงประกอบให้ทั้ง 3 สเตจ และย้ายเพลงสังเคราะห์เดิมของเกมไปอยู่ที่หน้าเมนูกับมินิเกมเป่า-ยิ้ง-ฉุบ Battle กติกาเกม ด่าน และตัวละครไม่เปลี่ยน

## สิ่งที่เปลี่ยน

- **เพลงประกอบสเตจ (ไฟล์ mp3):**
  - สเตจ 1 Grassland — *Morning Over Meadow Hills*
  - สเตจ 2 Forest — *Beyond the Treeline*
  - สเตจ 3 Boss Stage — *Siege of the Stone Keep*
- **การทำงานของเพลง:** เล่นวนซ้ำ หยุดเกมชั่วคราวแล้วเพลงพักไว้และเล่นต่อจากจุดเดิม เริ่มใหม่ ชนะ หมดเวลา หรือกลับหน้าแรกแล้วเริ่มจากต้น ปุ่มเปิด/ปิดเพลงควบคุมทั้งเพลง mp3 และเพลงสังเคราะห์ ความดังเพลงสเตจลดลงเหลือ 0.2
- **เพลงสังเคราะห์เดิมย้ายที่:** เล่นที่หน้าแรก หน้าเลือกตัวละคร หน้ารวมมินิเกม และเป่า-ยิ้ง-ฉุบ Battle เริ่มหลังผู้เล่นกดหรือแตะครั้งแรก (ข้อจำกัด autoplay ของเบราว์เซอร์) และหยุดเมื่อสลับไปแท็บอื่น Coin Rain ยังมีเพลงของตัวเองตอนเล่น ส่วน Memory Match ยังไม่มีเพลง
- **ผูกเพลงกับสเตจด้วย field `music`:** ระบุใน definition ของสเตจ (`js/level.js`, `js/stage-forest.js`, `js/stage-castle.js`) สเตจที่ไม่ระบุจะใช้เพลงสังเคราะห์ เล่นผ่าน `<audio>` จึงเปิดผ่าน `file://` ได้เหมือนเดิม
- **เอกสาร:** README และ MANUAL.md อัปเดตหัวข้อเพลง ตัวโน้ต และคำอธิบายที่ไม่ตรงกับเกมแล้ว

## สิ่งที่ผู้เล่นจะสังเกตได้

- เพลงสเตจ **ไม่เร่งจังหวะ** ตอนได้ดาว ใกล้หมดเวลา หรือบอสตื่น (เพลงสังเคราะห์ยังเร่งเหมือนเดิมในที่ที่ยังใช้อยู่)
- ไฟล์เพลงสเตจรวมกันราว 12.5 MB ผู้เล่นโหลดเฉพาะไฟล์ของสเตจที่เล่น
- iOS ไม่รับการปรับความดังของ `<audio>` เพลง mp3 จึงเล่นด้วยความดังเต็มของไฟล์ และอาจดังกว่าเสียงเอฟเฟกต์

## ขอบเขตการตรวจ

- ทดสอบด้วย Chromium headless (Playwright) ตามเส้นทาง หน้าแรก → เลือกตัวละคร → หน้ามินิเกม → เป่า-ยิ้ง-ฉุบ → Memory Match → เข้าทั้ง 3 สเตจ พร้อมหยุดเกม เล่นต่อ ปิดเพลง และกลับหน้าแรก: เพลงของแต่ละสเตจเล่นถูกไฟล์ เพลงสังเคราะห์เล่นเฉพาะหน้าเมนูและเป่า-ยิ้ง-ฉุบ และไม่มี error ใน console
- **ยังไม่ได้ตรวจ:** การฟังเสียงจริง (ตรวจเฉพาะว่าเพลงตัวไหนกำลังเล่น) รวมถึงว่าเพลงสเตจ 3 กลบเสียงยิงหรือเสียงบอสหรือไม่, มือถือและ iOS จริง, และการเล่นสเตจ 3 จนถึงฉากสู้บอส
- `tools/check-level.js` รันเกิน 2 นาทีโดยไม่จบ จึงหยุดไว้ก่อน (การแก้ไฟล์ด่านมีแค่เพิ่ม field `music`) ไม่นับเป็นผลผ่าน
