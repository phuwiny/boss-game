# Coin Quest — ผจญภัยเก็บเหรียญทอง

เกมแพลตฟอร์มเลื่อนฉากด้านข้าง (side-scrolling) แบบผู้เล่นคนเดียว

## โหมดเกม

| โหมด | เป้าหมาย |
|---|---|
| **โหมดปกติ** | เหรียญทอง 40 เหรียญกระจายอยู่ทั่วฉาก เก็บให้ได้ **20 เหรียญ** เร็วที่สุด |
| **โหมดจับเวลา** | มีเวลา **120 วินาที** เก็บเหรียญให้ได้มากที่สุด ฉากมีเหรียญ **80 เหรียญ** (มากกว่าโหมดปกติ 2 เท่า) ถ้าเก็บหมดก่อนเวลาจะจบทันที |

- **มินิเกมอื่นๆ:** มีปุ่มเตรียมไว้ในหน้าแรกแต่ยังกดไม่ได้ (ป้าย "เร็วๆ นี้") สำหรับเพิ่มเกมอื่นในอนาคต

## ตัวละคร

เลือกได้ที่ปุ่ม **ตัวละคร** ในหน้าแรก ระบบจะจำตัวที่เลือกไว้ ทุกตัวใช้ขนาดตัวสำหรับการชนเท่ากัน

| ตัวละคร | รูปลักษณ์ | จุดเด่น |
|---|---|---|
| **Bobo** (ตัวตั้งต้น) | ก้อนกลมสีส้ม คาดผ้าสีฟ้า | สมดุลทุกด้าน |
| **Mew** | เด็กผู้หญิงผมยาวสีเหลือง ตาสีเขียว เสื้อสีน้ำเงินเข้ม กระโปรงสีส้ม หมวกเบเร่สีดำ | วิ่งเร็วกว่าคนอื่น 25% |
| **Aclaire** | เด็กผู้หญิงผมสั้นสีส้มทรงหางม้า ตาสีฟ้า เสื้อแขนสั้นสีชมพู กางเกงสีน้ำเงิน | กระโดดสูงกว่าคนอื่นราว 30% |

ค่าความสามารถอยู่ใน `js/characters.js` (ตัวคูณ `run`, `accel`, `jump`)

## จุดเด่นอื่น ๆ

- **ด่านประจำวัน:** ตำแหน่งเหรียญและไอเทมสุ่มใหม่ทุกวัน ทุกคนเจอแบบเดียวกันในวันเดียวกัน จึงแข่งเวลากันได้
- **ไอเทม 3 ชนิด** (ชนิดละ 2 ชิ้นต่อด่าน มีผล 10 วินาที): ปีก = กระโดด 2 ชั้น, เห็ด = วิ่งเร็วขึ้น 1.5 เท่า, ดาว = อมตะ ชนศัตรูได้และเดินบนหนามได้ (ตกหลุมยังพลาด)

- เขียนด้วย HTML5 Canvas + CSS + JavaScript ล้วน **ไม่ต้อง build** ไม่มี dependency
- กราฟิกและเสียงสร้างด้วยโค้ดทั้งหมด (Canvas 2D + Web Audio API) ไม่มีไฟล์ภาพ/เสียง
- รองรับคอมพิวเตอร์ มือถือ (ปุ่มสัมผัสแบบ multi-touch) และจอยเกม (Gamepad API)
- พร้อมเผยแพร่บน GitHub Pages ทันที

## วิธีเล่น

| การกระทำ | คีย์บอร์ด | มือถือ | จอยเกม |
|---|---|---|---|
| เดินซ้าย/ขวา | `←` `→` หรือ `A` `D` | ปุ่ม ◀ ▶ มุมซ้ายล่าง | D-pad / analog ซ้าย |
| กระโดด | `Space` / `↑` / `W` | ปุ่มกระโดด มุมขวาล่าง | ปุ่ม A |
| หยุดชั่วคราว | `P` / `Esc` | ปุ่ม ⏸ มุมขวาบน | Start |
| เลือกตัวละคร (ในหน้าเลือกตัวละคร) | `←` `→` แล้ว `Enter` | แตะการ์ด | D-pad แล้วปุ่ม A |

เคล็ดลับ

- กดปุ่มกระโดดค้างเพื่อกระโดดสูง ปล่อยเร็วเพื่อกระโดดเตี้ย
- เหยียบหัวสไลม์เพื่อกำจัด (ชนด้านข้างจะพลาด)
- ระวังหนามแหลมและหลุม ถ้าพลาดจะกลับไปเริ่มที่ธงเช็กพอยต์ล่าสุด (เหรียญที่เก็บแล้วไม่หาย)
- สปริงสีแดงดีดตัวขึ้นที่สูง แผ่นไม้ลอยกระโดดทะลุจากด้านล่างได้
- มินิแมพด้านบนแสดงตำแหน่งเหรียญ (วงกลมสีทอง) และไอเทม (สี่เหลี่ยมข้าวหลามตัด) ที่ยังไม่ได้เก็บ
- ไอเทมที่ใช้งานอยู่แสดงเป็นแถบเวลาใต้มินิแมพ แถบกะพริบเมื่อเหลือไม่ถึง 2 วินาที
- ถ้าพลาด พลังจากไอเทมจะหายทั้งหมด
- เกมบันทึกสถิติของวันนี้และสถิติดีที่สุดตลอดกาลไว้ในเบราว์เซอร์ (localStorage) **แยกตามโหมดและตัวละคร** (โหมดปกติวัดเวลา โหมดจับเวลาวัดจำนวนเหรียญ)
- โหมดจับเวลา: นาฬิกาจะเป็นสีแดงเมื่อเหลือไม่ถึง 10 วินาที และมีเสียงนับถอยหลังใน 5 วินาทีสุดท้าย
- เปิดด่านแบบกำหนดเองได้ด้วย `?seed=ข้อความใดก็ได้` เช่น `index.html?seed=party` (ไม่บันทึกสถิติ)

## รันบนเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือรันผ่าน web server ใดก็ได้ เช่น

```bash
python -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## เผยแพร่ด้วย GitHub Pages

1. merge โค้ดเข้า branch `main` (หรือ branch ที่ต้องการใช้เผยแพร่)
2. ไปที่ **Settings → Pages** ของ repository
3. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที เกมจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ไฟล์ `.nojekyll` มีไว้ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ โดยไม่ผ่าน Jekyll
ทุก path ในโปรเจกต์เป็น relative path จึงทำงานได้ทั้งบน subpath ของ GitHub Pages และ custom domain

## โครงสร้างโปรเจกต์

```
index.html          หน้าเกม (HUD, ปุ่มสัมผัส, หน้าแรก/เลือกตัวละคร/หยุด/สรุปผล)
css/style.css       สไตล์และ layout แบบ responsive (รองรับ safe-area ของ iPhone)
js/level.js         ข้อมูลด่าน (ASCII map) และตัวแปลงด่าน
js/world.js         ฟิสิกส์ การชน และผลของไอเทม (ไม่ยุ่งกับ DOM ใช้ร่วมกับตัวตรวจด่านได้)
js/characters.js    ข้อมูลตัวละคร ชื่อ คำอธิบาย และตัวคูณความสามารถ
js/spawn.js         หาจุดที่วางของได้ และสุ่มวางเหรียญ/ไอเทมตาม seed รายวัน
js/render.js        การวาดภาพทั้งหมด: ฉาก parallax, tile, ตัวละครทั้ง 3 ตัว, อนุภาค, มินิแมพ
js/input.js         คีย์บอร์ด, ปุ่มสัมผัส multi-touch, จอยเกม
js/audio.js         เสียงเอฟเฟกต์และดนตรีประกอบ (Web Audio API)
js/main.js          game loop (fixed timestep 120 Hz), สถานะเกม, โหมด, เมนู, สถิติ, HUD
tools/check-level.js  ตัวตรวจด่าน (รันด้วย Node.js)
favicon.svg         ไอคอนเว็บ
```

## แก้ไขด่าน

ด่านอยู่ใน `js/level.js` เป็นตัวอักษรแบ่งเป็น "ส่วน" ต่อกันจากซ้ายไปขวา แต่ละส่วนสูง 18 แถว

| สัญลักษณ์ | ความหมาย | สัญลักษณ์ | ความหมาย |
|---|---|---|---|
| `.` | ว่าง | `^` | หนามแหลม |
| `#` | พื้นดิน | `S` | สปริง |
| `B` | บล็อกอิฐ | `o` | เหรียญแบบวางตายตัว (ไม่บังคับ) |
| `=` | แผ่นไม้ (ยืนได้จากด้านบน) | `P` | จุดเริ่มต้น |
| `~` | รางแพลตฟอร์มเคลื่อนที่ | `C` | ธงเช็กพอยต์ |
| `s` | สไลม์ (ศัตรู) | | |

เหรียญและไอเทมไม่ต้องวางเอง ระบบจะหาจุดที่วางได้จากรูปร่างด่านโดยอัตโนมัติ (เหนือพื้นหรือแผ่นไม้ 1–3 ช่อง ไม่ติดหนามหรือสปริง)
จำนวนเหรียญ เป้าหมาย รายการไอเทม และค่าของโหมดจับเวลา ตั้งค่าได้ที่ต้นไฟล์ `js/spawn.js` (`COINS`, `GOAL`, `ITEMS`, `TIMED_COINS`, `TIMED_TIME`)

หลังแก้ด่าน ให้รันตัวตรวจเพื่อยืนยันว่าข้อมูลถูกต้อง และทุกจุดที่ระบบอาจสุ่มวางของเก็บได้จริง

```bash
node tools/check-level.js
```

ตัวตรวจจะจำลองการเดิน/กระโดดทุกรูปแบบด้วยฟิสิกส์เดียวกับในเกม **ทีละตัวละคร** (ไม่ใช้ไอเทม ใช้เวลาประมาณ 30–60 วินาทีต่อตัว)
แล้วรายงานจุดที่เข้าถึงไม่ได้ (ถ้ามี) จากนั้นลองสุ่มวางแบบรายวันล่วงหน้า 1 ปี ทั้งโหมดปกติและโหมดจับเวลา เพื่อยืนยันว่าทุกวันได้ของครบและไม่ซ้อนกัน

ตรวจเฉพาะบางตัวละครได้ เช่น `node tools/check-level.js mew` (ใช้ตอนปรับค่าใน `js/characters.js`)
