## สเตจ

เลือกสเตจได้ที่หน้าแรก (ระบบจำสเตจที่เลือกไว้) ทุกสเตจเล่นได้ทั้ง 2 โหมด และบันทึกสถิติแยกกัน

| สเตจ | ลักษณะ |
|---|---|
| **สเตจ 1 Grassland** | ทุ่งหญ้า มีหลุมเหว บ่อหนาม สปริง แพลตฟอร์มเคลื่อนที่ ศัตรูคือสไลม์ |
| **สเตจ 2 Forest** | ป่าทึบ พื้นสูงต่ำหลายระดับและกิ่งไม้ซ้อนกันหลายชั้น **ไม่มีเหว** แต่มีหนามมากกว่าเล็กน้อย ศัตรูหลักคือหมูป่า |

## ศัตรู

| ศัตรู | พฤติกรรม |
|---|---|
| **สไลม์** | เดินช้า ๆ ไป-กลับ เหยียบหัวแล้วหายไป |
| **หมูป่า** (สเตจ 2) | เดินเร็วกว่าสไลม์เล็กน้อย **ไม่มีวันตาย** เหยียบแล้วสลบ 5 วินาที (มีดาวหมุนรอบหัว และสั่นก่อนตื่น) ระหว่างสลบเดินทะลุได้ไม่เป็นอันตราย และเหยียบซ้ำเพื่อนับ 5 วินาทีใหม่ได้ |

ชนศัตรูด้านข้างจะพลาด ถ้ามีดาวจะชนสไลม์กระเด็นได้ ส่วนหมูป่าจะสลบแทน

## โหมดเกม

| โหมด | เป้าหมาย |
|---|---|
| **โหมดปกติ** | เหรียญทอง 40 เหรียญกระจายอยู่ทั่วฉาก เก็บให้ได้ **20 เหรียญ** เร็วที่สุด |
| **โหมดจับเวลา** | มีเวลา **120 วินาที** เก็บเหรียญให้ได้มากที่สุด ฉากมีเหรียญ **80 เหรียญ** (มากกว่าโหมดปกติ 2 เท่า) ถ้าเก็บหมดก่อนเวลาจะจบทันที |

- **มินิเกมอื่นๆ:** มีปุ่มเตรียมไว้ในหน้าแรกแต่ยังกดไม่ได้ (ป้าย "เร็วๆ นี้") สำหรับเพิ่มเกมอื่นในอนาคต

## ตัวละคร

เลือกได้ที่ปุ่ม **ตัวละคร** ในหน้าแรก ระบบจะจำตัวที่เลือกไว้ ทุกตัวใช้ขนาดตัวสำหรับการชนเท่ากัน

| ตัวละคร | รูปลักษณ์ | ความสามารถ |
|---|---|---|
| **Bobo** (ตัวตั้งต้น) | ก้อนกลมสีส้ม คาดผ้าสีฟ้า | สมดุลทุกด้าน ไม่มีความสามารถพิเศษ |
| **Mew** | เด็กผู้หญิงผมยาวสีเหลือง ตาสีเขียว เสื้อสีน้ำเงินเข้ม กระโปรงสีส้ม หมวกเบเร่สีดำ | **กระโดด 2 ชั้น** ได้ตลอด และ**กดกระโดดค้างกลางอากาศเพื่อลอยตัว**นิ่งที่ความสูงเดิม (เดินซ้ายขวาได้) ใช้ได้รวม 5 วินาทีต่อการลอยหนึ่งครั้ง แตะพื้นแล้วได้คืนเต็ม |
| **Aclaire** | เด็กผู้หญิงผมสั้นสีส้มทรงหางม้า ตาสีฟ้า เสื้อแขนสั้นสีชมพู กางเกงสีน้ำเงิน | **วิ่งเร็วกว่าคนอื่น 25%** และ**โดนศัตรูหรือหนามแล้วไม่ตาย 1 ครั้ง** จะเด้งตัวและกะพริบเป็นอมตะ 5 วินาที (ได้คืนทุกครั้งที่เกิดใหม่ ตกเหวยังพลาด) |

- ค่าความสามารถอยู่ใน `js/characters.js`: ตัวคูณ `stats` (`run`, `accel`, `jump`) และ `ability` (`airJumps`, `float`, `guard`)
- ปีกเพิ่มกระโดดกลางอากาศอีก 1 ครั้ง (Mew ได้ปีกจะกระโดดได้ 3 ชั้น)
- HUD แสดงแถบเวลาลอยตัวของ Mew (เมื่อเริ่มใช้) และโล่ของ Aclaire (สว่าง = พร้อม, แถบลดลง = กำลังอมตะ, จาง = ใช้ไปแล้ว)

ตัวละครวาดแบบ **pixel art สไตล์ 16-bit** สูงราว 40 พิกเซล มีเส้นขอบเข้มและเงา 3 ระดับ (ตัวละครละ 9 ท่า: ยืน กะพริบตา วิ่ง 4 จังหวะ กระโดด ตก พลาด)
เกมปรับสเกลให้ 1 พิกเซลของตัวละครเท่ากับพิกเซลจอจำนวนเต็ม ภาพจึงคมทุกขนาดจอ ส่วนฉากยังเป็นภาพแบบเดิม

## จุดเด่นอื่น ๆ

- **ด่านประจำวัน:** ตำแหน่งเหรียญและไอเทมสุ่มใหม่ทุกวัน ทุกคนเจอแบบเดียวกันในวันเดียวกัน จึงแข่งเวลากันได้
- **ไอเทม 3 ชนิด** (ชนิดละ 2 ชิ้นต่อด่าน มีผล 10 วินาที): ปีก = กระโดด 2 ชั้น, เห็ด = วิ่งเร็วขึ้น 1.5 เท่า, ดาว = อมตะ ชนศัตรูได้และเดินบนหนามได้ (ตกหลุมยังพลาด)

- เขียนด้วย HTML5 Canvas + CSS + JavaScript ล้วน **ไม่ต้อง build** ไม่มี dependency
- กราฟิกและเสียงสร้างด้วยโค้ดทั้งหมด (Canvas 2D + Web Audio API) ไม่มีไฟล์ภาพ/เสียง รวมถึง sprite ตัวละครและ HUD แบบ pixel art
- รองรับคอมพิวเตอร์ มือถือ (ปุ่มสัมผัสแบบ multi-touch) และจอยเกม (Gamepad API)
- พร้อมเผยแพร่บน GitHub Pages ทันที

## วิธีเล่น

| การกระทำ | คีย์บอร์ด | มือถือ | จอยเกม |
|---|---|---|---|
| เดินซ้าย/ขวา | `←` `→` หรือ `A` `D` | ปุ่ม ◀ ▶ มุมซ้ายล่าง | D-pad / analog ซ้าย |
| กระโดด | `Space` / `↑` / `W` | ปุ่มกระโดด มุมขวาล่าง | ปุ่ม A |
| หยุดชั่วคราว | `P` / `Esc` | ปุ่ม ⏸ มุมขวาบน | Start |
| ลอยตัว (Mew) | กด `Space` / `↑` / `W` ค้างกลางอากาศ | กดปุ่มกระโดดค้าง | กดปุ่ม A ค้าง |
| เลือกสเตจ (หน้าแรก) | `Tab` ไปที่ปุ่มสเตจ แล้ว `←` `→` | แตะปุ่มสเตจ | - |
| เลือกตัวละคร (ในหน้าเลือกตัวละคร) | `←` `→` แล้ว `Enter` | แตะการ์ด | D-pad แล้วปุ่ม A |

เคล็ดลับ

- กดปุ่มกระโดดค้างเพื่อกระโดดสูง ปล่อยเร็วเพื่อกระโดดเตี้ย
- เหยียบหัวสไลม์เพื่อกำจัด เหยียบหมูป่าให้สลบ 5 วินาทีแล้วเดินผ่านไป (ชนด้านข้างตอนหมูป่าตื่นจะพลาด)
- ระวังหนามแหลมและหลุม ถ้าพลาดจะกลับไปเริ่มที่ธงเช็กพอยต์ล่าสุด (เหรียญที่เก็บแล้วไม่หาย)
- สปริงสีแดงดีดตัวขึ้นที่สูง แผ่นไม้ลอยกระโดดทะลุจากด้านล่างได้
- มินิแมพด้านบนแสดงตำแหน่งเหรียญ (วงกลมสีทอง) และไอเทม (สี่เหลี่ยมข้าวหลามตัด) ที่ยังไม่ได้เก็บ
- HUD แบบเกมคลาสสิก: กรอบเหรียญและเวลามุมซ้ายบน (โหมดจับเวลามีแถบเวลาที่เปลี่ยนเป็นสีส้มแดงเมื่อใกล้หมด)
  ไอเทมที่ใช้งานอยู่แสดงเป็นแถบพลังใต้กรอบ แถบกะพริบเมื่อเหลือไม่ถึง 2 วินาที
- ถ้าพลาด พลังจากไอเทมจะหายทั้งหมด
- เกมบันทึกสถิติของวันนี้และสถิติดีที่สุดตลอดกาลไว้ในเบราว์เซอร์ (localStorage) **แยกตามสเตจ โหมด และตัวละคร** (โหมดปกติวัดเวลา โหมดจับเวลาวัดจำนวนเหรียญ) สถิติของสเตจ 1 ใช้ key เดิม สถิติที่ทำไว้ก่อนมีหลายสเตจจึงยังอยู่
- โหมดจับเวลา: นาฬิกาจะเป็นสีแดงเมื่อเหลือไม่ถึง 10 วินาที และมีเสียงนับถอยหลังใน 5 วินาทีสุดท้าย
- เปิดด่านแบบกำหนดเองได้ด้วย `?seed=ข้อความใดก็ได้` เช่น `index.html?seed=party` (ไม่บันทึกสถิติ)

## เผยแพร่ด้วย GitHub Pages

1. merge โค้ดเข้า branch `main` (หรือ branch ที่ต้องการใช้เผยแพร่)
2. ไปที่ **Settings → Pages** ของ repository
3. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที เกมจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ไฟล์ `.nojekyll` มีไว้ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ โดยไม่ผ่าน Jekyll
ทุก path ในโปรเจกต์เป็น relative path จึงทำงานได้ทั้งบน subpath ของ GitHub Pages และ custom domain

## โครงสร้างโปรเจกต์

```
index.html          หน้าเกม (HUD, ปุ่มสัมผัส, หน้าแรก/เลือกตัวละคร/หยุด/สรุปผล)
css/style.css       สไตล์และ layout แบบ responsive (รองรับ safe-area ของ iPhone)
js/level.js         ตัวแปลงด่าน รายชื่อสเตจ (CQ.STAGES) และข้อมูลสเตจ 1 Grassland (ASCII map)
js/stage-forest.js  ข้อมูลสเตจ 2 Forest (ASCII map)
js/world.js         ฟิสิกส์ การชน ความสามารถตัวละคร ศัตรู (สไลม์/หมูป่า) และผลของไอเทม (ไม่ยุ่งกับ DOM ใช้ร่วมกับตัวตรวจด่านได้)
js/characters.js    ข้อมูลตัวละคร ชื่อ คำอธิบาย ตัวคูณ และความสามารถพิเศษ
js/sprites.js       ตัวสร้าง sprite ตัวละครแบบ pixel art (รูปทรง + เงา + เส้นขอบ) ไม่ยุ่งกับ DOM
js/hud.js           HUD แบบพิกเซล: กรอบ ตัวเลขพิกเซล ไอคอน แถบเวลา/แถบความสามารถ/แถบไอเทม
js/spawn.js         หาจุดที่วางของได้ และสุ่มวางเหรียญ/ไอเทมตาม seed รายวัน
js/render.js        การวาดภาพทั้งหมด: ธีมฉากแต่ละสเตจ (parallax, tile, ของตกแต่ง), ศัตรู, ตัวละคร (จาก sprites.js), อนุภาค, มินิแมพ, HUD
js/input.js         คีย์บอร์ด, ปุ่มสัมผัส multi-touch, จอยเกม
js/audio.js         เสียงเอฟเฟกต์และดนตรีประกอบ (Web Audio API)
js/main.js          game loop (fixed timestep 120 Hz), สถานะเกม, สเตจ, โหมด, เมนู, สถิติ, HUD
tools/check-level.js  ตัวตรวจด่าน (รันด้วย Node.js)
favicon.svg         ไอคอนเว็บ
```

## แก้ไขด่าน

ด่านเป็นตัวอักษรแบ่งเป็น "ส่วน" ต่อกันจากซ้ายไปขวา แต่ละส่วนสูง 18 แถว สเตจ 1 อยู่ใน `js/level.js` สเตจ 2 อยู่ใน `js/stage-forest.js`
เพิ่มสเตจใหม่ได้โดยสร้างไฟล์ `js/stage-*.js` ที่เพิ่มตัวเองเข้า `CQ.STAGES` (ดูตัวอย่างจาก `js/stage-forest.js`) แล้วใส่ `<script>` ใน `index.html` และรายชื่อไฟล์ใน `tools/check-level.js`
ตั้ง `noPits: true` ให้สเตจที่ห้ามมีเหว ตัวตรวจด่านจะตรวจว่าแถวล่างสุดเป็นพื้นทุกคอลัมน์

| สัญลักษณ์ | ความหมาย | สัญลักษณ์ | ความหมาย |
|---|---|---|---|
| `.` | ว่าง | `^` | หนามแหลม |
| `#` | พื้นดิน | `S` | สปริง |
| `B` | บล็อกอิฐ | `o` | เหรียญแบบวางตายตัว (ไม่บังคับ) |
| `=` | แผ่นไม้ (ยืนได้จากด้านบน) | `P` | จุดเริ่มต้น |
| `~` | รางแพลตฟอร์มเคลื่อนที่ | `C` | ธงเช็กพอยต์ |
| `s` | สไลม์ (ศัตรู) | `h` | หมูป่า (ศัตรู สลบได้ ไม่ตาย) |

เหรียญและไอเทมไม่ต้องวางเอง ระบบจะหาจุดที่วางได้จากรูปร่างด่านโดยอัตโนมัติ (เหนือพื้นหรือแผ่นไม้ 1–3 ช่อง ไม่ติดหนามหรือสปริง)
จำนวนเหรียญ เป้าหมาย รายการไอเทม และค่าของโหมดจับเวลา ตั้งค่าได้ที่ต้นไฟล์ `js/spawn.js` (`COINS`, `GOAL`, `ITEMS`, `TIMED_COINS`, `TIMED_TIME`)

หลังแก้ด่าน ให้รันตัวตรวจเพื่อยืนยันว่าข้อมูลถูกต้อง และทุกจุดที่ระบบอาจสุ่มวางของเก็บได้จริง

```bash
node tools/check-level.js
```

ตัวตรวจจะจำลองการเดิน/กระโดดทุกรูปแบบด้วยฟิสิกส์เดียวกับในเกม **ทุกสเตจ ทีละตัวละคร**
(ไม่ใช้ไอเทม ไม่กดกระโดดกลางอากาศ และปิดการกันตาย จึงตรวจแบบระมัดระวัง ใช้เวลาประมาณ 40 วินาทีต่อตัว ส่วน Mew ราว 2–3 นาทีเพราะจำลองการลอยตัวด้วย)
แล้วรายงานจุดที่เข้าถึงไม่ได้ (ถ้ามี) จากนั้นลองสุ่มวางแบบรายวันล่วงหน้า 1 ปี ทั้งโหมดปกติและโหมดจับเวลา เพื่อยืนยันว่าทุกวันได้ของครบและไม่ซ้อนกัน

ตรวจเฉพาะบางสเตจหรือบางตัวละครได้ เช่น `node tools/check-level.js forest` หรือ `node tools/check-level.js grassland aclaire`

## แก้หน้าตาตัวละคร (pixel art)

sprite ไม่ได้เก็บเป็นไฟล์ภาพ แต่สร้างตอนเริ่มเกมจาก `js/sprites.js`
- ส่วน `DEFS` วาดตัวละครแต่ละตัวจากรูปทรง (วงรี รูปหลายเหลี่ยม เส้นหนา) ด้วยพิกัดหน่วยเกม แล้วลงเงาตามทิศแสงอัตโนมัติ
- สีของแต่ละส่วนเป็นชุดโทน `l` (สว่าง) `b` (ปกติ) `s` (เงา) `d` (เงาเข้ม) สีเสื้อ/กระโปรงอยู่ใน `NORMAL` (ตอนได้ดาวจะสลับเป็นสีรุ้ง)
- ตา ปาก ปกเสื้อ เป็นลายพิกเซลวาดมือ (`stampAt`)
- ขนาด 1 พิกเซลของ sprite = `UNIT` หน่วยของเกม (0.85) ขนาด hitbox ไม่เปลี่ยนตามภาพ
